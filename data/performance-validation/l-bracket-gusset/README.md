# 带三角加强筋的 L 型件

按用户示意图建模：水平底板、垂直立板，以及连接两者的三角形拉伸加强筋。
所有尺寸单位为 **mm**，`case.json` 是可维护的尺寸与验收定义。

| 部件 | 尺寸与位置 |
| --- | --- |
| 底板 | 80 × 60 × 8，X=0..80，Y=0..60，Z=0..8 |
| 立板 | 80 × 8 × 60，X=0..80，Y=0..8，Z=8..68 |
| 三角加强筋 | 厚 8，沿 X 拉伸；X=36..44 |
| 加强筋截面 | YZ 平面直角三角形，顶点 (8,8)、(48,8)、(8,58) |
| 加强筋水平／竖直直角边 | 40 / 50 |
| 整体包围盒 | 80 × 60 × 68 |
| 理论体积 | 38400 + 38400 + 8000 = 84800 mm³ |

三部分通过布尔融合形成 **一个连续实体**，不是三个重叠显示的物体。没有倒角、圆角或孔。
`model_report.json` 记录有效性、精确尺寸、体积和 STEP 重新读取验证。
拍摄导入时按整个实体的体积质心平移到原点。

本样例验证组合零件重建能力。识别器自动估计长方体数量，并将斜面加强筋恢复为
三角截面拉伸体。完整恢复的尺寸误差需 ≤0.5 mm，对称差体积需 ≤5%；
误识别出局部长条或仅覆盖整个包围盒都不能算成功。

生成和运行方法见上级目录 README。生成图片、点云与报告保存于
`outputs/performance-validation-l-bracket-gusset/`。

## 2026-10-04 初始实现的失败记录

62 个已知毫米尺度相机位姿，GPU 稠密点云 544,302 点，预处理后 66,550 点。
拍摄、匹配、三角化、稠密重建与点云预处理均完成。

联合五类图元诊断保留了 10 个平面，并产生 1 个低置信圆柱候选和 1 个低置信圆锥候选。
本源模型全部由平面组成，这两个曲面候选属于误检，不能当成真实零件特征。

第一次完整运行的生产箱体/孔识别路径返回
`CGAL Efficient RANSAC found no supported primitive`，未构造 CAD。
该旧错误文本没有标明平面或圆柱检测阶段，不能仅凭它确定哪个阶段失败。
原始报告保留为 `validation_report.initial.json` 和 `fitting_report.initial.json`。

补充具体失败阶段诊断后，使用同一份点云快速复拟合一次：联合诊断检出 11 个平面，
生产路径却把零件误解释为约 **80.054 × 8.005 × 8.015 mm 的长条体**。
误识别候选虽可生成有效 B-Rep 并导出 STEP，但 Y / Z 尺寸分别误差约 51.995 / 59.985 mm，
体积误差 93.954%，对称差体积 93.980%。`cad_accuracy_failed` 明确拒绝了该结果。
该次错误 STEP 已归档为 `reconstructed-before-refit-*.step`，不能作为通过结果。

这两次旧识别流程都未通过 CAD 验收。两组图像重建共享 GPU，本次耗时
不用于比较独占 GPU 性能。原始失败报告保留，供新旧实现对照。


## 组合拟合更新后：通过

使用原有 544,302 点稠密点云复拟合，未重新拍摄或运行 COLMAP：

- 自动识别 **2 个长方体 + 1 个三角截面拉伸加强筋**。
- 检测到的材料网格中，长方体数量的最小值已由搜索证明；没有把加强筋阶梯化。
- 提交为两个 BoxPrimitive、一个三角草图和一个 Join Extrude，融合为一个有效实体。
- X/Y/Z 尺寸误差为 0.041867 / 0.029760 / 0.014475 mm。
- 对称差体积为 1.158129%，通过 5% 阈值；独立体积采样的保守上界为 1.908613%。
- STEP 导出、重新读取、实体数量与体积检查通过。

当前 `outputs/performance-validation-l-bracket-gusset/reconstructed.step` 是通过验收的
L 型件。最新结构化报告为同目录 `fitting_report.json` 与 `validation_report.json`。
Studio 已接入相同的 `reconstructParametricSolid()` 入口。

无图像重建的回归测试还覆盖单体、共面合并、重叠、T/U 型、三/四层台阶、分离物块、
任意整体旋转与打乱点序；分别使用理想点云与 0.02 mm 位置噪声。生成和验收脚本：
`tools/generate_compound_test_clouds.py`、`tools/run_compound_fit_tests.py`。
