# 大底板混合特征点云

这是直接从解析几何采样的混合特征测试输入，不经过图片重建，也不依赖识别算法。
生成器：`tools/generate_mixed_template_board.py`（依赖 NumPy、Matplotlib）。

```powershell
python tools/generate_mixed_template_board.py
```

输出：`outputs/mixed-template-board/`。默认点间距约 1 mm，随机种子 4500。
布局采用错落锚点叠加随机位置扰动，矩形类特征各自绕 Z 轴旋转 15–36°，
高度错开。默认每版 497,359 点，整体包围盒 600 × 360 × 100 mm。
`exact/cloud.ply` 为无噪声版；`noisy/cloud.ply` 的 XYZ 各分量叠加标准差
0.02 mm 的独立高斯噪声，法向仍保留解析真值。两版点序相同且已打乱。
如需更细采样，可使用 `--spacing 0.5 --output outputs/mixed-template-board-fine`。

坐标系为右手系，Z 向上，单位 mm。底板覆盖 X=0..600、Y=0..360、Z=0..8。
所有加料特征从上表面 Z=8 开始，孔只贯穿底板。底面、侧面和孔内壁均有采样；
连接处内部接触面已移除。底板与全部凸台、L 型件组成连续材料，不能当作若干
独立封闭实体点云简单拼接；特征的 XY 占地相互分离。

矩形类绕各自局部原点旋转，正角度为从 +Z 看向底板时的逆时针方向。
孔轴和圆柱/圆台轴保持垂直底板。表中是默认种子结果，实际参数以输出
`case.json` 为准；改变 `--seed` 会改变位置和旋转，生成器拒绝越界或占地重叠。
默认旋转后占地 AABB 的最小间距为 55.549 mm（保守间隔）。

L 型件直接读取相邻 `l-bracket-gusset/case.json` 的全部尺寸参数，保留原始
80 × 60 × 8 底座、80 × 8 × 60 立板以及厚 8、直角边 40/50 的三角加强筋，
进行刚体旋转和平移后放到大底板上，保留内部各部件之间的几何关系。

PLY 使用 binary little endian，字段为 XYZ、单位外法向 NX/NY/NZ、RGB。
颜色标识特征方便观察，不作为几何识别真值接口。每个版本旁边的
`reconstruction.json` 标记毫米单位；请与 PLY 一起保留。

`ground_truth.npz` 按 PLY 行顺序保存 `feature_id` 和 `surface_patch_id`。
`surface_patches.json` 解释面片 ID，`case.json` 记录源几何，
`generation_report.json` 记录点数及校验结果，`preview.png` 提供三维与俯视布局。
真值文件供验收使用，不能作为自动拟合输入。

生成器检查全部精确点的内侧有材料、外侧为空，法向长度、有限数、重复点、
特征占地间隙、孔中心贯通，并重新读取 PLY 二进制数据校验写入。
这些生成检查验证输入点云。共享曲面重构后的完整模型验收另外运行：

```powershell
python tools/run_mixed_feature_fit_tests.py
```

默认在 `outputs/shared-surface-mixed-validation/` 保存独立参考 STEP、无噪声/噪声版
重建 STEP、体积差报告以及逐部件参数验收。拟合只读取点云及单位元数据，源尺寸和
标签用于单独验收。完整调用链与当前能力边界见 `docs/Shared_Surface_Analysis_Refactor.md`。
