# 带中心贯穿孔的长方体

所有尺寸单位为 **mm**，`case.json` 是可维护的尺寸与验收定义。

| 项目 | 数值 |
| --- | --- |
| 长方体 X × Y × Z | 60 × 40 × 20 |
| 贯穿孔直径 | 12 |
| 孔轴 | Z 方向，穿过 (30, 20) |
| 孔深 | 20，完整贯穿 |
| 理论体积 | 48000 − 720π ≈ 45738.053289 mm³ |
| 源模型范围 | X=0..60，Y=0..40，Z=0..20 |

`model.step` 是单一实体，`model_report.json` 记录实体有效性、精确尺寸、体积及
STEP 写入后重新读取的验证结果。拍摄导入时按体积质心平移到原点。

验收要求：各轴尺寸误差不超过 0.5 mm；识别一个直径误差不超过 0.5 mm 的贯穿孔；
重建与源实体的对称差体积不超过源体积的 5%。对称差同时检查位置、方向和孔的恢复，
只有识别箱体、丢失孔不算完整 CAD 成功。

生成和运行方法见上级目录 README。生成图片、点云与报告保存于
`outputs/performance-validation-box-through-hole/`。

## 2026-10-04 实测

62 个已知毫米尺度相机位姿，GPU 稠密点云 675,791 点，预处理后 67,516 点。
重建得到一个长方体和一个贯穿孔，参数化 B-Rep 和 STEP 回读均有效，精度验收通过。

| 指标 | 实测 |
| --- | --- |
| X / Y / Z 外形尺寸绝对误差 | 0.031251 / 0.028236 / 0.016616 mm |
| 识别孔径 | 11.784618 mm |
| 孔径绝对误差 | 0.215382 mm |
| 体积相对误差 | 0.341081% |
| 对称差体积 / 源体积 | 0.870324% |

这是虚拟拍摄样例的单次基准结果，尚未测量多次运行成功率或现实拍摄效果。
两组样例共享 GPU 执行，本次耗时不用于比较独占 GPU 性能。
原始报告：`outputs/performance-validation-box-through-hole/validation_report.json`；
重建模型：`outputs/performance-validation-box-through-hole/reconstructed.step`。
