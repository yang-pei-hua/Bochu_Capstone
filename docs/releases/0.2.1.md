# ParamCAD Studio 0.2.1

重建得到的 Box、贯穿孔和圆柱现在可以在特征面板修改参数，撤销/重做或保存后继续编辑。Box 六面和圆柱端面上的新草图可以依附所属特征，修改上游尺寸后下游草图与实体重新定位。

## 交付内容

- Box 尺寸、贯穿孔直径、圆柱半径/高度编辑；Box 固定中心或六面，圆柱固定底面/顶面/中心。
- 参数与 B-Rep 原子提交和失败回滚，revision 防止过期编辑覆盖，最多 50 步当前会话 CAD 撤销/重做。
- 手动修改保护；自动重拟合暂停覆盖，显式替换要求确认。
- Box 六面、Cylinder 底面/顶面的语义支持平面；依赖查询、完整删除提示与级联删除。
- `.pcad` v2 保存语义引用、编辑参数、参照方式和保护标记；兼容读取 v1。旧客户端不能读取 v2。
- 模型显示变换与建模坐标分离；草图、基准面和实体使用同一显示变换，绘制尺寸保持模型毫米值。
- 场景树右键显示/隐藏/删除模型或点云，空资产节点隐藏。

## 范围

语义引用描述源特征的支持平面，不保证经过布尔运算后某个有限面仍存在。共面归属不唯一、导入 STEP 或不支持的面使用固定平面，界面提示其不会跟随上游尺寸。已有固定平面草图不会自动迁移。任意布尔结果面稳定命名、一般几何关系求解、跨会话撤销、真实照片可靠性评测和文本修改仍是后续工作。
