# ParamCAD Studio 0.2.2

新增限定中文参数修改：在右侧特征页输入「高度增加 2 mm，固定中心」「#3 的孔直径改为 8 mm」等指令，先预览目标、尺寸和固定参照，并在模型副本上验证依赖重建，再应用。支持长方体、圆柱和贯穿孔，毫米/厘米/米换算及增减百分比。输入、选择、模型或工程变化会使预览失效；提交复用撤销/重做、手动编辑保护、语义面跟随、工程保存和 STEP 导出。

同时包含点云可靠性修复：稳健体素尺度和离群阈值、观测锚定的缺失法向定向、未定向法向自动实体拒绝、退化邻域与极端体素索引保护。49 项合成压力契约通过（35 项精度通过、14 项明确拒绝），2 份已有虚拟拍摄稠密点云精度通过；真实机械扫描泛化仍待带真值数据验收。

基础中文语法与适用范围见 [文字参数修改](../Text_Parameter_Editing.md)，点云评测见 [可靠性评测](../Cloud_Reliability_Validation.md)。自由自然语言和文本重拟合尚未接入。

离线包默认版本更新为 0.2.2；工程格式继续使用版本 2，兼容读取版本 1。

验证通过：Release 客户端完整构建、20 项客户端 CTest、独立几何核心 CTest、30 项工具层 Python 测试，以及 49 项点云可靠性压力契约。原生界面测试还覆盖文字预览、失效、撤销重做、依赖面跟随、工程重开和 STEP 导出。
